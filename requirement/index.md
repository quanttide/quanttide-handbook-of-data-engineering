# Requirement — 数据需求文档（DRD）格式

> 格式：Markdown | 受众：客户/业务方

DRD 的定义与"三个问题"见 specification 仓（quanttide-specification-of-data-engineering）`requirement/index.md`。

---

## 1. 格式与位置

### 1.1 格式

DRD MUST 使用 Markdown 格式。DRD 的受众是客户和业务方，MUST NOT 包含 YAML 结构或技术实现细节。

### 1.2 文件位置

DRD 文件 MUST 存放在 `.quanttide/data/requirement/` 目录下。

文件命名 SHOULD 使用项目标识符，如 `<project-name>.md`。

---

## 2. 结构定义

一份符合规范的 DRD MUST 包含以下章节。

三个问题与章节的映射：**为什么做** → [2.1 业务目标](#21-业务目标)；**有什么输入** → [2.2 数据范围](#22-数据范围) + [2.3 输入要求](#23-输入要求)；**要什么输出** → [2.4 输出期望](#24-输出期望)。[2.5 约束与假设](#25-约束与假设) 与 [2.6 验收标准](#26-验收标准) 补充上下文与完成判据。

### 2.1 业务目标

| 字段 | 约束 |
|------|------|
| `业务目标` | MUST 存在且非空。自然语言描述，说明项目要解决的业务问题和预期价值。判定：章节存在且有实质内容（非空、非仅标题） |

### 2.2 数据范围

| 字段 | 约束 |
|------|------|
| `数据范围` | MUST 存在且非空。描述数据来源、类型和预估规模。SHOULD 包含数据敏感度说明（是否需要脱敏） |

### 2.3 输入要求

| 字段 | 约束 |
|------|------|
| `输入要求` | MAY 存在（默认省略）。描述客户需要提供的数据：文件格式、字段说明、交付方式和频次。如果客户无需提供数据（数据由我方采集），MAY 省略 |

### 2.4 输出期望

| 字段 | 约束 |
|------|------|
| `输出期望` | MUST 存在且非空。描述期望的交付物：格式（CSV/JSON/Parquet）、结构（面板数据/长表/文档分类结果）、关键指标定义 |

### 2.5 约束与假设

| 字段 | 约束 |
|------|------|
| `约束与假设` | MAY 存在（默认省略）。列出已知的约束条件：时间、预算、数据质量假设、合规要求 |

### 2.6 验收标准

| 字段 | 约束 |
|------|------|
| `验收标准` | MUST 存在且非空。可验证的完成判据列表。每条标准 MUST 可被"通过/不通过"判定；判定由项目相关方（人工或工具）执行，DRD 本身不限定判定方式 |

---

## 3. 模板

```markdown
# <项目名称> — 数据需求文档

## 业务目标

<项目要解决的业务问题，用自然语言描述>

## 数据范围

<数据来源、类型、规模、敏感度>

## 输入要求

<客户需要提供的文件、格式、频次。如无则省略>

## 输出期望

<期望的交付物：格式、结构、关键指标>

## 约束与假设

<时间/预算/质量假设/合规要求。如无则省略>

## 验收标准

- [ ] <可验证的判据 1>
- [ ] <可验证的判据 2>
```

---

## 4. 示例

```markdown
# GHTorrent 用户活动数据提取 — 数据需求文档

## 业务目标

从 GHTorrent 开源数据库的 MySQL dump 中，为一批指定的 GitHub 用户提取每日活动面板数据，用于开源社区行为研究。

## 数据范围

- 来源：GHTorrent MySQL dump（公开数据）
- 规模：数百 GB 原始数据，数万目标用户
- 敏感度：输出需对用户标识做脱敏处理

## 输入要求

- 目标用户 ID 列表（CSV，每行一个 GitHub 用户 ID）
- 由客户在项目启动时提供

## 输出期望

- 格式：CSV
- 结构：面板数据，每行 = 一个用户一天的全部活动聚合
- 关键指标：push 次数、PR 次数、Issue 评论次数等多项活动指标
- 控制变量：bot 识别标记（识别结果可作为筛选或统计维度）

## 约束与假设

- 时间：两周内完成
- 质量：bot 识别准确率优先于覆盖率
- 数据需去重

## 验收标准

- [ ] CSV 每日一行，列数固定
- [ ] 用户标识已脱敏
- [ ] Bot 识别结果可复现
- [ ] 去重验证通过（无重复行）
```
